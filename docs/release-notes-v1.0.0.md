# v1.0.0 release notes

**Release notes prepared on 19 October 2026.**

## Shipped
- Local Manifest V3 Chrome Extension and Flask API.
- English transcript retrieval, chunked DistilBART summary generation, controlled errors, and 12 tests.
- Pinned compatible dependencies and project documentation.

## Known limits
- Supports eligible English transcripts only.
- Local only; not published to the Chrome Web Store.
- Generative output can omit or distort details; long videos can produce fragmented summaries.

## Handover
Repository includes local setup, test instructions, requirements, risks, decisions, and retrospective. Improved implementation was developed with AI assistance; tutorial attribution remains pending confirmation.
